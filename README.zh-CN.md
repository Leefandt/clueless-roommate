# 无能的室友.skill

> 一个 Claude Code 技能：让 AI 扮演一个没学过你这门课的室友。你先完整讲一遍自己的理解；他记下漏洞，再逐点拷打，直到你能用大白话把他讲明白。

这是费曼技巧的互动版。没有答题界面，没有当场的分数，只有一个一直问"为啥"的困惑室友。

**怎么避免被带偏：** 你先完整讲一遍，中途不被打断；他的每个问题都必须引用你的原话，或你整段没提的概念；攻击地图是有限的，所以对话不会无限跑偏，也有明确的结束点。

**English version: [Clueless Roommate](README.md)** · 英文版为主版本。

## 为什么有用

- **费曼技巧**：讲不清 = 没真懂。
- **生成效应**：自己组织语言，比反复看书有效。
- **误解辨别**：纠正一个"听起来对"的错误，比复述定义更难，也更接近考试。
- **没有考试感**：室友不评分、不夸人，压力低，但漏洞藏不住。

## 一段对话

```text
你：      我懂了，来考我。
室友：    行，你先别管我。你用 5-10 分钟把这块完整讲一遍——从"样本方差为什么除以 n-1"讲到"它什么时候成立"，假设我完全没学过。讲完说"讲完了"。
你：      （完整讲一遍，卡住就跳过去）
室友：    行，我记了几个地方，一个个来。你刚才说"数据离自己的均值总比离真实均值更近"——你给我个具体数字，我看看是不是每个点都更近？
...
室友：    行，我大概顺了。你去忙吧，我再消化消化。
```

然后它出戏，给一段简短、诚实的简报：**稳 / 基本稳 / 还虚**，并分开写"你自己讲到的"和"问了才补上的"。

## 四种室友水平

开场选择，默认第 1 档——最纯的费曼模式。

| 水平 | 他是谁 | 练什么 |
|---|---|---|
| **1 完全不懂**（默认） | 零基础，术语全靠你翻译 | 标准费曼：把话讲成人话 |
| **2 略懂一点** | 学过一点，知道几个术语 | 精确表达、区分相近概念、条件 |
| **3 不懂装懂** | 嘴上"懂了懂了"，其实没懂 | 教学闭环：讲完要验证对方真的懂 |
| **4 懂装不懂** | 其实学过，装傻试你 | 抗压、严谨、防自满；收尾揭晓 |

推荐先用 **1**；想练"讲完怎么确认学生真懂"用 **3**；想被刁难用 **4**。

## 怎么用

1. 把课件 / 讲义 / 笔记发给 Claude（PDF、PPTX、DOCX、图片、markdown 都行），说 **"讲讲这节"** 或 **"直接考我"**。
2. 如果让它先讲：听完说 **"我懂了"**。
3. 它会让你先完整讲一遍（5-10 分钟）；卡住就跳过去；讲完说 **"讲完了"**。
4. 然后它会逐条拷打；正常回答，一次只答一个问题。
5. 卡住说 **"暂停"**；想换点说 **"跳过"**；想结束说 **"结束"**。

触发词："室友模式"、"扮演我室友"、"我懂了，来考我"、"检验我是不是真懂了"、"费曼一下"。

### 控制词

| 说 | 会发生什么 |
|---|---|
| `暂停` / `出戏` / `等等` | 出戏解释当前点，问是否回戏 |
| `跳过` | 换攻击点 |
| `跳过自述` | 至少讲 3 句总纲，然后直接进入拷打 |
| `结束` / `停` / `先到这` | 直接收尾 |
| `狠一点` | 多设误解陷阱和边界题，少给提示 |
| `温柔点` | 多给具体例子和一次额外提示 |
| `换个水平` | 在四档知识水平之间切换 |
| `换个设定` | 调整室友的名字 / 性格 / 专业 |
| `继续上次` | 读最近的 session 文件接上 |
| `不记录` | 本次不写 session 文件 |
| `不要简报` | 出戏一句就结束，不给判定 |

进度默认写到 `~/roommate-sessions/`。

## 它怎么运转

```text
0 收料 → 1 讲解（可选） → 2A 完整自述 → 2B 逐点拷打 → 3 收尾
```

- **2A 完整自述**：你不被打断地讲完一整块。室友只记笔记，内部生成一张有限的**攻击地图**：覆盖、缺口、错误、矛盾、边界。
- **2B 逐点拷打**：他一次问一个问题，每个问题都引用你的原话，或你整段没提的核心概念。攻击地图打完 / 12-18 个问题 / 你喊停，就收。
- **3 收尾**：简报分开写"你自己讲到的"和"问了才补上的"（`prompted`）。

核心设计：**室友能感知"我没听懂"，但不能判定"你讲错了"。** 他不讲解、不当场纠正、不透露分数。他的困惑就是诊断信号。能把一个真困惑的人讲明白，你大概率是真的懂了。

内部有两层评分：

```text
S 自述基线（你自己讲出来的）：
0 没提 / 1 只提名字或定义 / 2 讲了 why 或例子 / 3 讲了 why + 例子 + 条件

D 拷打防守（被问之后）：0-3，按证据表

F = D，标记 spontaneous / prompted / unresolved。
"稳"要求每个核心概念 S >= 2 且 D >= 2；
凡是问了才补上的核心概念，最多只能判"基本稳"。
```
