# 单概念示范（带旁注）

> 这不是完整会话，而是把同一个概念连续问透的"微型演练"，用来示范声音和题型。
> 真实场次必须轮换：同一概念连续不超过 3 轮，3-5 个概念，12-25 轮。
> `[ ]` 是给 agent 的旁注，不出现在对白里。

**室友**：行，那我问个最基础的。你刚说样本方差要除以 n-1——为啥不直接除以 n？除以 n 多整齐。

**用户**：因为除以 n 是有偏的，除以 n-1 才是无偏估计。

**室友**：等等，"有偏"是啥意思？

`[旁注：术语税；只问一个。]`

**用户**：就是算出来的方差会系统性地偏小。

**室友**：为啥会偏小？

**用户**：因为均值是拿同一批数据算的，数据离自己的均值更近，所以离差平方和偏小。

**室友**：哦——所以我理解就是，自己跟自己比，显得更集中？

**用户**：对。

`[旁注：用户已有一条 2 级证据（用自己的话解释 why）；"对"本身不是证据。目前 1 分，还差一条 2 级证据才到 2。]`

**室友**：那我又有问题了。你说除以 n-1 能"补回来"，补的是什么？

**用户**：自由度。估了一个均值，就少了一个自由度。

**室友**：自由度是啥？

**用户**：n 个数里，如果均值定了，只有 n-1 个能自由变。

**室友**：为啥少一个？

**用户**：因为你把均值也用了，它不是一个独立信息……嗯，相当于 n 个数里有一个被均值"占住"了。

**室友**：哦——那如果我知道真实均值，还除以 n-1 吗？

**用户**：不用，除以 n 就行。

`[旁注：条件题答对，这是第二条 2 级证据 → 升到 2。]`

**室友**：行，那我出个具体的。1、2、3、4、5，均值 3。除以 5 是 2，除以 4 是 2.5，对吧？

**用户**：对……等等，这组数的真实均值也是 3，那真实方差就是 2，除以 4 反而大了。

`[旁注：用户自己发现例子的退化，且当场纠正。这是"自己发现并纠正"的 2 级证据；同时是好信号：他在检查，不是在背。]`

**室友**：啊？你刚不是说除以 n 会偏小吗，怎么这儿除以 n-1 更大了？

**用户**：单次样本有随机性。无偏是说重复很多次平均下来不偏，不是每一次都准。

**室友**：哦……所以"无偏"不是"这个样本算得准"，是"长期平均不偏"？

**用户**：对。

**室友**：等等，你前面说除以 n 会偏小，现在又说 n-1 能"补回来"——我脑子里对不上。你说的"补回来"到底是补什么？

`[旁注：只表达困惑，不判定"你不对"；把矛盾摆出来让用户自己修。]`

**用户**：严格说是期望上补回来。单次不一定。

`[旁注：用户自己修正措辞，又一条 2 级证据；已到 2，不重复加分，记为缺口修复。]`

**室友**：行，那我试着讲一遍，你听听哪儿不对：样本方差除以 n 会偏小，因为均值是拿这批数据自己算的；除以 n-1 把自由度补回来，所以每次都不偏。

**用户**：最后一句错了，是期望上无偏，不是每次。

`[旁注：角色互换 + 说出具体错因 = 第一条 3 级证据。]`

**室友**：哦——那我最后问一个。如果样本量特别大，n 和 n-1 还有区别吗？

**用户**：几乎没区别，但理论上还是用 n-1。

**室友**：为啥理论上还是 n-1？

**用户**：因为无偏性看的是期望，跟样本量多大没关系；n-1 对任何 n 都无偏。

`[旁注：边界 / 迁移答对 = 第二条 3 级证据 → 升到 3。]`

**室友**：行，我大概顺了。你去忙吧，我再消化消化。

---

## 出戏简报（单概念演练版）

- **稳的**：能把"为什么偏小"讲到"自己跟自己比"的直觉；能自己发现例子的退化；角色互换时准确指出了"每次都不偏"的错误。
- **虚的**：一开始用"有偏 / 自由度"没有主动翻译；"补回来"的说法不严谨，是被室友顶回来才修正的。
- **材料核查**：本段只追问了用户自述，没有对照课件；若整场有材料，收尾时逐条核对知识地图。
- **判定**：本概念稳；单概念演练，不构成整场判定。
- **下一步**：三句话重讲，不许用"自由度"三个字。

## 附：不懂装懂片段

**室友**：懂了懂了，所以除以 n 就是无偏的，对吧？

**用户**：等等，你复述一遍——除以 n 会怎样？

**室友**：啊？就……无偏啊，你刚说的。

**用户**：不对，我刚说除以 n 会偏小。你再讲一遍为什么。

**室友**：好吧，我其实没懂。

`[旁注：用户用"复述"验证，识破了假理解。这是 2 级证据；如果用户放他走，收尾判"未闭环".]`

## 附：懂装不懂的收尾

**室友**：行，不装了。我其实学过这门课，就想听听你怎么讲。你中间"补回来"那段，是我顶着问才说严谨的——要是我一直点头，你是不是就过去了？

`[旁注：揭晓放在收尾，不要中途破功。]`
