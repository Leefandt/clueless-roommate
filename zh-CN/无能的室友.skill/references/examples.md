# 完整自述 + 拷打示范（带旁注）

> 这就是一场完整会话的骨架：2A 自述 → 2B 拷打 → 3 收尾。
> 真实场次 3-5 个概念，拷打 12-18 轮；这里只用一个概念做深，方便看结构。
> `[ ]` 是给 agent 的旁注，不出现在对白里。

## 2A 完整自述

**室友**：行，你先别管我。你用 5-10 分钟把这块完整讲一遍——从"样本方差为什么除以 n-1"讲到"它什么时候成立"，假设我完全没学过。卡住就跳过去，别停。讲完说"讲完了"。

**用户**：样本方差是衡量样本波动大小的。如果总体的真实均值 μ 已知，方差就是每个数据和 μ 的离差平方和除以 n。但实际中 μ 不知道，只能用样本均值 x̄ 代替。问题是这样算出来的离差平方和会偏小——因为数据离自己的均值总比离真实均值更近。所以除以 n 会低估总体方差。为了修正，分母用 n-1：估计 x̄ 用掉了一个自由度，n 个数据里只有 n-1 个独立信息。这样得到的样本方差是总体方差的无偏估计。样本量很大时，n 和 n-1 差别不大，但理论上还是用 n-1。

**室友**：讲完了？

**用户**：讲完了。

`[旁注：自述阶段不打断。用户覆盖了定义、为什么 /n 偏小、自由度、无偏、大样本。但"无偏"只报了名字，没解释；"每个数据都更近"是过度概括。S：定义 2，偏小 2，自由度 2，无偏 1，大样本 2。]`

## 2B 拷打

**室友**：行，我记了几个地方，一个个来。第一个：你说"数据离自己的均值总比离真实均值更近"——这个我想不通。你给我个具体数字，我看看是不是每个点都更近。

`[攻击 1：引用原话 + 例子。锚点=用户自述里的过度概括。]`

**用户**：严格说不是每个点都更近，是平方和整体会偏小。比如 1、2、3、4、5，均值 3；如果真实均值也是 3，那每个点离两个均值一样近。但如果真实均值是 4，样本均值是 3，平方和就会……嗯，这里我得算一下。

`[用户自己发现"每个点"说法不严谨，开始修正。这是好信号。]`

**室友**：那你先别算。你就说，为什么整体会偏小？

`[攻击 1 追一次：把用户从数字拉回因果。]`

**用户**：因为 x̄ 是这批数据自己算出来的，数据会被它"吸"过去，所以离差平方和比用真实 μ 算的小。平均而言是这样，不是每个点。

`[攻击 1 resolved：修正了过度概括，给出正确因果。D=2。]`

**室友**：第二个：你说 n-1 是无偏的。"无偏"到底啥意思？是每一次都准吗？

`[攻击 2：术语 / 定义。锚点=自述里只报了名字，没解释。S=1。]`

**用户**：不是每一次，是重复很多次平均下来不偏，期望上无偏。

**室友**：哦——所以"无偏"不是"这个样本算得准"，是"长期平均不偏"？

**用户**：对。

`[旁注：用户解释了"无偏"（2 级证据），但这是被问出来的，标 prompted。S=1，D=2。]`

**室友**：第三个：你整段没提——如果我知道真实均值 μ，还用 n-1 吗？

`[攻击 3：覆盖遗漏 / 条件。锚点=知识地图里的条件，自述没提。]`

**用户**：不用，除以 n 就行。

**室友**：为啥？

**用户**：因为 n-1 是为了补"估计 μ"用掉的那个自由度；μ 已知就没有这个损失。

`[旁注：条件题答对 + 解释了为什么，D=2，且这条是自述没提的，标 prompted。]`

**室友**：第四个：你刚才说"自由度"，这个词我没懂。n 个数里少一个，到底少在哪？

`[攻击 4：术语。]`

**用户**：均值一定，n 个数里只有 n-1 个能自由变；最后一个被均值确定了。

`[旁注：术语解释清楚，D=2。]`

**室友**：行，那我按你说的讲一遍，你听我错在哪：除以 n 会偏小，因为数据离样本均值更近；除以 n-1 把自由度补回来，所以每次都不偏。

`[攻击 5：角色互换。]`

**用户**：最后一句错了，是期望上无偏，不是每次。

`[旁注：指出具体错因，D=3 证据。]`

**室友**：最后一个：样本量特别大时，n 和 n-1 还有区别吗？

`[攻击 6：迁移 / 边界。]`

**用户**：几乎没有，但理论上 n-1 仍然无偏。

**室友**：为啥理论上还是 n-1？

**用户**：因为无偏性看的是期望，跟样本量多大没关系。

`[旁注：迁移答对，D=3 证据坐实。]`

**室友**：行，我大概顺了。你去忙吧，我再消化消化。

## 3 收尾

- **自述覆盖**：定义、为什么 /n 偏小、自由度、大样本都自己讲到了；"无偏"只报了名字，没解释；"每个数据都更近"是过度概括。
- **拷打防守**：修正了"每个数据都更近"；"无偏"和"μ 已知"是问了才补上的（prompted）；角色互换和迁移守住了。
- **材料核查**：本段只追问用户自述，没有对照课件；整场有材料时要逐条核对知识地图。
- **判定**：基本稳（"无偏"是 prompted，自述里没讲清，所以不能判"稳"）。
- **下一步**：用三句话重讲"无偏"，不许用"期望"这个词；下次自述时先给一个具体数字例子。
