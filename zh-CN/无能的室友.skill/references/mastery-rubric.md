# 掌握度判定（内部）

## 等级

- **0 讲不出**：无法用自己的话说明这个概念，或只说"就是那个……"。
- **1 背定义**：能复述术语 / 定义 / 公式，但一问"为什么"或"举个例子"就卡。
- **2 能解释**：能用自己的话讲清"为什么 / 怎么来的"，并能应对条件、例子或误解中的至少一类。
- **3 能迁移**：能在新情境里正确使用，能纠正具体错误，能说清边界。

## 唯一证据表

计分只看这张表。每条证据必须能引用用户原话。

| 证据 | 支持 |
|---|---|
| 说出定义 / 核心结论 | 1 |
| 用自己的话解释因果（不是背材料，也不是复述状态 1 里你讲的话） | 2 |
| 自造一个正确例子（不是课件原题） | 2 |
| 正确回答适用条件 / 范围 | 2 |
| 识别并纠正一次误解（室友的或自己的），说出具体错因 | 2 |
| 在新情境 / 极端情况下判断正确 | 3 |
| 纠正角色互换里的错误，并说清错因 | 3 |
| 回答或主动说出边界 / 失效条件 | 3 |

**到 1**：1 条 1 级证据。

**到 2**：至少 2 条不同的 2 级证据，且无未修正硬伤。

**到 3**：已经到 2，且至少 2 条不同的 3 级证据，且无未修正硬伤。

规则：

- 同一条证据不重复计。
- 解释术语"是什么" = 1 级；解释"为什么这个结论成立" = 2 级。
- 一次回答最多升一级；从 1 到 3 必须跨轮次。
- 用户说"对 / 嗯 / 不知道"不是证据；室友的复述也不是。
- 你状态 1 里讲过的内容，用户复述得再顺也只能算 1 级。
- 没有原话引用 = 没有证据；分数保持不变或下降，不许凭印象加分。

## 硬伤与纠正窗口

- 同意一个错误陈述 = 记一个硬伤，不立刻降级。
- 在概念关闭前（该概念最后一次追问结束前）自己发现并纠正 → 硬伤解除，并算一条 2 级证据。
- 到收尾仍未纠正 → 该概念封顶 1，整场判定至少降一档。
- 用户没机会发现（室友没继续追）不算硬伤，但材料核查里写"未验证"。

硬上限（满足任一，该概念封顶 1）：

- 关键步骤被追问两次仍讲不清。
- 术语无法翻译成人话。
- 前后矛盾，被指出后仍无法解释。

## 知识水平模式的影响

- **完全不懂**：标准证据表。
- **略懂一点**：标准证据表；用户使用室友已懂的术语不算术语税；对比和条件题的证据更重要。
- **不懂装懂**：标准证据表 + 教学闭环。
  - 至少一次用"复述 / 举例 / 做题"验证室友（问"你懂了吗"不算）→ 才算完成。
  - 没验证就放他走 → 判定不能是"稳"；按证据表该"还虚"就还是"还虚"，简报点明"他带着错误走了"。
  - 识破假理解按"识别并纠正一次误解"计（2 级证据），不重复计；主动验证并让室友暴露错误 = 一条 3 级证据（仅本模式）。
- **懂装不懂**：标准证据表；室友的"困惑"是装的，不能当诊断信号；按用户答案本身判。收尾揭晓。

## 记录

- 每 4-5 轮更新一次 session 文件，不要等收尾再回忆。
- 每条：轮次 / 概念 / 分数 / 用户原话（逐字） / 缺口。
- 用户说"不记录"时不写文件，但仍然在上下文里保留原话和分数。

## 收尾条件

满足任一：

1. 所有核心概念 ≥2，且至少一个 3，且无未修正硬伤。
2. 总轮次到 25（硬上限）。
3. 用户说结束 / 明显疲劳。
4. 已过 12 轮，所有概念都至少被探过两次，且没有更多信息可挖。

- 12 轮前不收尾，除非用户主动结束、明显疲劳，或材料只够一个概念。
- 25 轮必须停；没达标判"还虚"，点名没探到的概念。
- 不要为了凑"全部 ≥2"拖堂；也不要因为用户想听好话提前收。

## 收尾简报（≤8 行）

- **稳的**：1-3 点，具体到"你能把 X 讲到 Y 程度"。
- **虚的**：1-3 点，引用用户原话或卡点。
- **材料核查**：用户讲错但室友从无知视角没法拆穿的地方。无材料写"无课程材料，未能核对课程口径"；无法判断写"无法核查"。
- **判定**：稳 / 基本稳 / 还虚。
- **下一步**：一个最小复述任务（"用三句话重讲 X，不许用 Y 这个词"）；可选 48 小时后二轮。

判定：

- **稳**：核心概念全部 ≥2，至少一个 3，无未修正硬伤。
- **基本稳**：全部 ≥2，但缺少 3 级证据，或有一个已修复的小缺口。
- **还虚**：有概念 <2，或有未修正的硬伤，或被用户带过去的错误理解。

## 反注水

- 不许为了让用户开心写"你完全掌握了"。
- 不许把"室友最后说懂了"当成掌握证据——室友可能只是放弃了。
- 判定必须指向原话证据；写不出就降一档。
- 只有收尾时回答"我到底行不行"；对话中室友装傻。
