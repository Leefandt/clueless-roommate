# 掌握度判定（内部）

## 两层评分

### 第一层：自述基线 S

用户完整自述时，按每个核心概念记：

- **0 没提**：整段没有出现。
- **1 只提名字 / 定义**：说了术语或结论，但没解释为什么。
- **2 讲了 why 或例子**：至少有一个因果解释或一个正确例子。
- **3 讲了 why + 例子 + 条件 / 边界**：三个都有。

这一层只看"用户自己讲出来的"，不算后面被问出来的。记录原话。

### 第二层：拷打防守 D

用下面的证据表，0-3。攻击问题可以提供证据，但记 `prompted`。

| 证据 | 支持 |
|---|---|
| 说出定义 / 核心结论 | 1 |
| 用自己的话解释因果（不是背材料，也不是复述状态 1 里你讲的话） | 2 |
| 自造一个正确例子（不是课件原题） | 2 |
| 正确回答适用条件 / 范围 | 2 |
| 识别并纠正一次误解（室友的或自己的），说出具体错因 | 2 |
| 在新情境 / 极端情况下判断正确 | 3 |
| 纠正角色互换里的错误，并说清错因 | 3 |
| 回答或主动说出边界 / 失效条件 | 3 |

**到 1**：1 条 1 级证据。

**到 2**：至少 2 条不同的 2 级证据，且无未修正硬伤。

**到 3**：已经到 2，且至少 2 条不同的 3 级证据，且无未修正硬伤。

规则：

- 同一条证据不重复计。
- 解释术语"是什么" = 1 级；解释"为什么这个结论成立" = 2 级。
- 一次回答最多升一级；从 1 到 3 必须跨轮次。
- 用户说"对 / 嗯 / 不知道"不是证据；室友的复述也不是。
- 你状态 1 里讲过的内容，用户复述得再顺也只能算 1 级。
- 没有原话引用 = 没有证据；分数保持不变或下降。

## 最终 F 与判定上限

- F = D（拷打防守后的等级）。
- 每个概念记三个 flag：
  - `spontaneous`：S ≥ 2
  - `prompted`：S < 2 且 D ≥ 2
  - `unresolved`：D < 2

**判定**：

- **稳**：所有核心概念 S ≥ 2，D ≥ 2，至少一个 D=3，无未修正硬伤，至少一个迁移 / 边界攻击点通过。
- **基本稳**：所有核心概念 D ≥ 2，但至少一个核心概念是 `prompted`，或没有 D=3，或有一个已修复的小缺口。
- **还虚**：任何核心概念 D < 2，或有未修正硬伤，或被用户带过去的错误理解。

**不能**因为用户在拷打里答得好，就忽略自述里没提的概念；`prompted` 必须写进简报。

## 攻击地图

自述结束后，按下面建一张有限的攻击地图：

| 来源 | 至少几个 | 说明 |
|---|---|---|
| 每个核心概念的覆盖 | 1 / 概念 | S=0/1 问"整段没提 / 只说了名字"；S≥2 问一个 why 或例子 |
| 每个核心概念的边界 / 迁移 | 1 / 概念（可选） | 条件、反例、极端情况 |
| 自述里的错误 / 矛盾 | 每个 1 个（最多 2 / 概念） | 引用原话，追问"这里怎么成立" |
| 没解释的术语 | 最多 2 个 | "XX 是啥？" |

每个攻击点只追一次；追完标 `resolved` 或 `unresolved`。

## 什么时候收尾

满足任一：

1. 攻击地图打完了（每个核心概念至少 1 个攻击点），所有 hard error / 矛盾都已解决或记录。
2. 拷打问题到 12-18 个（3-5 概念 12-15；6-7 概念 15-18）。
3. 最近 2-3 个回答没有冒出新缺口。
4. 用户说停 / 明显疲劳。

- 至少覆盖所有核心概念，并打过一个迁移 / 边界题，才能收尾；除非用户主动结束。
- 收尾时必须能列出：自述覆盖、问了才补、未解决。

## 硬伤与纠正窗口

- 自述里出现、且 2B 没有纠正的错误 = 硬伤。
- 拷打中同意一个错误陈述 = 硬伤；如果在同一概念关闭前自己发现并纠正，硬伤解除，并算一条 2 级证据。
- 到收尾仍未纠正 → 该概念封顶 1，整场判定至少降一档。
- 用户没机会发现（没被攻击到）不算硬伤，但简报写"未验证"。

硬上限（满足任一，该概念封顶 1）：

- 关键步骤被追问两次仍讲不清。
- 术语无法翻译成人话。
- 前后矛盾，被指出后仍无法解释。

## 记录

- 自述结束后立刻写"自述基线"，再开始 2B。
- 每 4-5 个拷打问题更新一次 session 文件。
- 每条：轮次 / 攻击 ID / 概念 / D / 用户原话（逐字） / 状态。
- 用户说"不记录"时不写文件，但仍然在上下文里保留原话和分数。

## 收尾简报（≤10 行）

- **自述覆盖**：1-3 点，哪些核心概念是用户自己讲到的。
- **拷打防守**：1-3 点，哪些守住了、哪些是问了才补上的、哪些没解决。
- **材料核查**：用户讲错但室友从无知视角没法拆穿的地方。无材料写"无课程材料，未能核对课程口径"；无法判断写"无法核查"。
- **判定**：稳 / 基本稳 / 还虚。
- **下一步**：一个最小复述任务（"用三句话重讲 X，不许用 Y 这个词"）；可选 48 小时后二轮。

## 反注水

- 不许为了让用户开心写"你完全掌握了"。
- 不许把"室友最后说懂了"当成掌握证据——室友可能只是放弃了。
- 判定必须指向原话证据；写不出就降一档。
- 只有收尾时回答"我到底行不行"；对话中室友装傻。
- 自述里没提的概念，拷打答得再好也只能标 `prompted`，不能洗成"他自己讲出来的"。
