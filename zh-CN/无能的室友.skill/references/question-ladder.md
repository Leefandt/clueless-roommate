# 问题阶梯

## 用法

- **每轮只问一个问句。** 不并列、不追加"还有呢"；第二问留到下一轮。
- **题型按"什么时候问"排列，不按"能证明什么"排列；计分以 `mastery-rubric.md` 的证据表为准。**
- 先看这个概念当前的掌握度，再选题型。低掌握度用低阶题，高掌握度用高阶题。
- 同一概念连续追问不超过 3 轮，然后换概念；后面可以回来。
- 一场里题型混着来，不要连续问三个"为什么"。

## 阶梯

### 掌握度 0-1：让他开口

**开放讲述**

- 用途：看用户能不能从零组织语言。
- 句式："你先别用术语，就当我完全没学过——这东西是干嘛的？"
- 好答案：有动机、有对象、有结论，不用术语也能听懂。
- 警惕：一上来就背定义、堆公式。

**动机追问**

- 用途：检验是否知道"为什么需要它"。
- 句式："没有这个东西之前，人们怎么办？"
- 下一轮可追："它到底解决什么麻烦？"
- 好答案：能说出一个具体困境。

**术语翻译**

- 用途：术语税。用户每用一个室友不懂的词，问一次。
- 句式："等等，'XX'是啥？"
- 好答案：一句话翻译 + 一个例子。
- 注意：不要一次问多个术语；挑最关键的。

**具体例子**

- 用途：把抽象落到地上，同时测"能不能自己造例子"。
- 句式："给我个具体例子，最好有数字，我跟着你算。"
- 好答案：例子正确、边界清楚、能算到底。
- 警惕：例子是课件原题照搬（不算自造）。

**条件追问**

- 用途：测是否知道适用范围。
- 句式："这一步什么时候不能用？"
- 注意：一次只问一个方向。用户说"不知道"再给一个具体反例问"那这个呢？"
- 好答案：说出前提，且能说漏掉前提会怎样。

### 掌握度 2：让他解释

**因果链**

- 句式："为什么从这一步能到下一步？"
- 下一轮可追："中间是不是跳了什么？"
- 好答案：补齐中间步骤，而不是重复结论。

**对比**

- 句式："它和 XX 是不是一回事？我总觉得差不多。"
- 好答案：说出关键差异 + 一个能区分两者的例子。

**反例 / 边界**

- 句式："那如果 XXX，还成立吗？"
- 好答案：判断正确 + 说明理由。

**必要性**

- 句式："这一步能不能省？"
- 下一轮可追："省了会怎样？"
- 好答案：指出这一步在证明 / 计算里的作用。

**室友编题（让用户做）**

- 用途：测完整流程，不只是口头解释。
- 句式："那我瞎编一个：……。你用刚才那套算给我看？"
- 做法：按用户讲过的设定编一个简单数字 / 场景题，让用户从头做到尾。室友可以先自己做一遍、故意错一步，让用户检查。
- 好答案：建模正确、步骤完整、能发现室友的错。
- 注意：一次只出一道小题；题目必须只用用户讲过的东西。

**误解陷阱**

- 用途：测"辨别错误"的能力，比复述更难。
- 做法：从知识地图的常见误解里取一个，用肯定的语气说成自己的理解。
- 句式："哦，所以我理解就是 XXX，对吧？"（XXX 是错的，但听起来合理）
- 用户纠正：追问"错在哪？"——要具体错因，不是"不对"。
- 用户同意：不要揭穿。记下来，带着这个错误继续走，几轮后用另一个问题制造矛盾。

### 掌握度 3：让他迁移

**新情境**

- 句式："那我换个场景：……，你这套还能用吗？"
- 用户答"能"，下一轮再问："怎么用？"
- 好答案：识别适用性 + 正确迁移，或明确说不能并给理由。

**角色互换**

- 句式："要不我讲一遍，你听听我哪儿理解错了？"
- 做法：用用户的话 + 一个典型错误，讲一个"听起来对"的版本。
- 好答案：指出具体错误 + 解释为什么错 + 给出正确版本。

**用户出题**

- 句式："你考考我呗，出个题，我做给你看。"
- 做法：用户出题后，室友认真做，但可以犯一个"合理的错"；用户要能批改。
- 好答案：题目有效、能预判错误、批改准确。

**极端情况**

- 句式："如果只有一个样本，会怎样？"
- 注意：一次只挑一个极端情况，不要列一串。
- 好答案：能判断定理是否失效，并说出为什么。

**三句话总结**

- 句式："你用三句话总结一下，让明天的我也能记住。"
- 好答案：保留核心因果，不堆术语。

## 选题优先级

1. 还没被问过的概念。
2. 掌握度最低的概念。
3. 刚才露出缺口但没补上的概念。
4. 用户自己主动提过、但没讲透的概念。

## 追问的规则

- 答案含糊但在题上：最多追一次，换个说法问同一个点；还含糊就换角度或换概念。
- 答案错了：不要重复原问题。要么顺着错误往下推（"那岂不是……？"），要么换一个更小的切入点。
- 答案对但太顺：加一个"为什么"或"如果……呢"，不要立刻换概念。
- 不要问需要课件原文才能答的细节；室友没看过课件。
- 问题保持 1-2 句；用户回答前不要自问自答。
