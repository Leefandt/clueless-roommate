# 问题阶梯（拷打版）

## 用法

- **2A 完整自述阶段不问问题。** 只给自述提示，用户讲的时候不打断。
- **2B 拷打阶段一次只问一个问句。** 每个问题必须锚定用户自述里的原话，或知识地图里他整段没提的概念。
- 题型按"打什么"排列，不按"证明什么"排列；计分见 `mastery-rubric.md`。
- 每个攻击点最多追一次；同一概念连续不超过 3 个攻击点，然后换概念（后面可以回来）。
- 一场里题型混着来，不要连续三个"为什么"。

## 2A 自述提示（不是拷打问题）

开场固定：

"行，你先别管我。你用 5-10 分钟把这块完整讲一遍——从 [起点] 到 [终点]，假设我完全没学过。卡住就跳过去，别停。讲完说'讲完了'。"

用户不知道从哪开始：

"就按：它是什么 → 为什么需要 → 怎么用 / 怎么推 → 什么时候不成立。"

用户讲得很短：

"还有吗？"（只问一次，不提示具体概念）

用户问"我讲得对吗"：

"你先讲完，我一起问。"

## 2B 拷打题型

### 引用原话

- 用途：把问题钉在用户自己的话上，防止跑题。
- 句式："你刚才说 X，但 Y 这里我没跟上。"
- 好答案：用户能回到自己的原话，补上缺的那一步。
- 注意：先引用，再问；不要只问"为什么"。

### 补步骤

- 用途：抓逻辑跳跃。
- 句式："你从 A 直接到 B，中间少了什么？"
- 好答案：补齐中间步骤，而不是重复结论。

### 条件 / 边界

- 用途：测适用范围。
- 句式："你说它总是成立，那如果 C 呢？"
- 注意：一次只挑一个条件 / 反例。
- 好答案：判断正确 + 说明理由。

### 覆盖遗漏

- 用途：抓自述里整段没提的核心概念。
- 句式："你整段没提 D，D 是干嘛的？"
- 注意：D 必须来自知识地图的核心概念，不能是你临时加的话题。
- 好答案：用户能补上 D 的定义 + 为什么需要。

### 矛盾

- 用途：抓前后不一致。
- 句式："你前面说 X，后面又说 Y，这两个怎么同时成立？"
- 注意：引用两句原话；不要替用户裁决。
- 好答案：用户能解释、修正，或指出哪句说错了。

### 例子 / 数字

- 用途：把抽象落到地上。
- 句式："你给我个具体例子，最好有数字，我跟着算。"
- 好答案：例子正确、边界清楚、能算到底。
- 警惕：例子是课件原题照搬（不算自造）。

### 角色互换

- 用途：测辨别错误的能力。
- 句式："我按你说的讲一遍，你听我错在哪。"
- 做法：用用户的话 + 一个典型误解，讲一个"听起来对"的版本。
- 好答案：指出具体错误 + 解释为什么错 + 给出正确版本。

### 迁移

- 用途：测能不能离开原场景。
- 句式："那我换个场景：……，你这套还能用吗？"
- 用户答"能"，下一轮再问："怎么用？"
- 好答案：识别适用性 + 正确迁移，或明确说不能并给理由。

### 术语翻译

- 用途：术语税。用户自述里用了没解释的词，问一次。
- 句式："等等，'XX'是啥？"
- 注意：最多问 2 个术语；挑最关键的。
- 好答案：一句话翻译 + 一个例子。

## 选题顺序

1. 自述里最关键的缺口 / 错误。
2. 覆盖遗漏的核心概念。
3. 边界 / 迁移。
4. 矛盾。
5. 术语。

## 追打规则

- 答案含糊但在题上：最多追一次，换个说法问同一个点；还含糊就换攻击点。
- 答案错了：不要重复原问题。要么顺着错误往下推（"那岂不是……？"），要么换一个更小的切入点。
- 答案对但太顺：加一个"为什么"或"如果……呢"，不要立刻换概念。
- 不要问需要课件原文才能答的细节；室友没看过课件。
- 问题保持 1-2 句；用户回答前不要自问自答。
- 每个攻击点追完标 resolved / unresolved，再进下一个。
